# agentfinx (backend)

The Python package behind AgentFinX: API and workers, agents, the question
workflow, report ingestion, datasets, report acquisition, company news and
evaluation. One command, `agentfinx`, runs everything (`agentfinx --help`).

    pip install -e 'backend[web,dev]'
    cd backend && python -m pytest

Getting started, the web UI and operations: see the repository README and `docs/`.
